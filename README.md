# 魁北克 Uber 法语与英语听说学习站

面向法语 A1 学习者的 **90 天自主学习课程**，重点练习魁北克收费载客驾驶相关的法语词汇、阅读、听力及情景理解，同时提供适合英语 B2 水平的职场沟通训练。

## 在线学习

- 网站： https://jonney2021.github.io/french/
- 课程从 **第 1 天至第 90 天** 编号，不关联日历日期，任何时候都可以开始。
- 使用手机、平板或电脑浏览器学习，无需安装 App，也不需要注册账号。

## 功能

- **每日课程**：法语词汇、中文释义、例句、基础语法、阅读理解及模拟选择题。
- **词汇发音**：点击词汇、例句或句子旁的发音按钮，听取法语朗读。
- **听力训练**：提供 12 组独立编写的司机与乘客情景对话，支持正常速度、慢速、字幕显示与听后答题；对话在课程中循环复习。
- **语音选择**：优先使用设备可用的加拿大法语 `fr-CA` 声音，可自行选择发音语音及语速。
- **英语听说**：经理工作沟通、任务汇报、问题解释和口语问答练习。
- **进度记录**：在本设备浏览器保存已完成课程的打卡状态。

## 法语音频说明

网站内的词汇与情景对话使用浏览器或设备提供的**合成语音**，不是魁北克真人录音；发音质量取决于所选择的语音引擎。若设备没有 `fr-CA` 声音，可以安装法语（加拿大）文字转语音组件并重新启动浏览器。

另提供外部**真人法语**音视频资源，便于熟悉加拿大及魁北克的自然语速和口音：

- [Mauril](https://mauril.ca/fr/)
- [Radio-Canada OHdio](https://ici.radio-canada.ca/ohdio)
- [魁北克政府法语学习资源](https://www.quebec.ca/education/apprendre-le-francais/outils-ressources)

## 学习建议

工作日参考每天 60 分钟法语、20 分钟英语的安排。学习完成后在课程页面打卡。学习记录只保存在当前浏览器的本地存储中，不会同步至 GitHub 或其他设备；清除浏览器网站数据后可能丢失进度。

## 关于考试

本网站的练习题为自行编写的学习材料，**并非 SAAQ 官方试题，也不能代替正式培训**。魁北克司机资格、培训和考试要求以相关机构公布的规定为准。

## GitHub Pages 部署

进入仓库的 **Settings → Pages**，在 **Build and deployment** 选择 **Deploy from a branch**，分支选择 `master`，目录选择 `/(root)` 并保存。发布后可通过上面的在线学习地址访问。
