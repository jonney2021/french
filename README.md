# 90 天法语与英语听说学习站

面向法语 A1 学习者的 **90 天自主学习课程**，重点练习日常交流、出行服务相关的法语词汇、阅读、听力及情景理解，同时提供适合英语 B2 水平的听力和口语训练。

## 在线学习

- 网站：https://jonney2021.github.io/french/
- 课程按照 **第 1 天至第 90 天** 编号，不关联日历日期，可随时开始。
- 支持通过电脑或手机浏览器访问，无需注册账号。

## 主要功能

- **每日课程**：法语词汇、中文释义、例句、基础语法、阅读理解及模拟选择题。
- **词汇与例句发音**：点击发音按钮朗读法语词汇和句子。
- **互动听力**：提供日常出行与服务场景对话，支持正常速度、慢速、字幕切换和听后答题。
- **语音设置**：可选择浏览器提供的法语声线并调节语速。
- **英语听说**：日常交流、职场表达、听力理解与口语对话练习。
- **学习进度**：在当前设备浏览器中保存完成状态。

## 学习建议

可参考每天 60 分钟法语、20 分钟英语的学习安排，结合自己的时间灵活调整。每天完成课程后可在页面打卡。

学习进度仅保存于本设备浏览器，不会自动同步至其他设备；清除浏览器数据可能导致记录丢失。

## 学习资料声明

练习题与情景对话是独立编写的语言学习材料，并非任何考试机构的官方试题；正式培训、考试或职业资格要求应以相应机构的最新规定为准。
